# Goblin Ages

Yeni, bağımsız **Godot 4** PC oyun projesi.

## Açılış
1. Bu ZIP dosyasını çıkarın.
2. Godot Engine → **Import** → klasördeki `project.godot` dosyasını seçin.
3. Projeyi açıp **F6** (ana sahneyi çalıştırmak için **F5**) tuşuna basın.

## İlk test
- Basit 3D test alanı ve geçici goblin karakteri.
- WASD veya yön tuşlarıyla hareket.
- Kamera karakteri takip eder.

Bu sahne yalnızca teknik başlangıçtır; oyunun türü, sanat tarzı ve mekanikleri henüz kararlaştırılmadı.
